# ADR 0020：有序平台工作、独立会话收发与关联诊断

状态：实施完成，本地整合验证通过，等待两平台CI构建。日期：2026-11-07。

## 背景

第一批隔离显示器查询后，双机有线对照仍有一次应用RTT尖峰与TCP重传增量同窗。该事件不能归因为某个同步平台调用，第二批也不承诺修复网络丢包或驱动问题。但代码审查确认光标确认、拖放读取、回执清理持锁磁盘访问，以及会话发送等待耦合读取，均可让其他工作不必要地停顿。

用户选择继续开发。本批保留原网络配置与传输默认，开发验证不启动真实键鼠钩子、不覆盖安装版。

## 平台调用的顺序与生命周期

控制端的start/grab/release与被控端inject/lock/hide由各自串行平台线程执行。核心任务异步等待确认，必须先完成grab才能发Enter、先完成定位/归还才能继续后续状态；键钮、移动和隐藏按提交顺序执行。工作队列有界，调用方只有一项在飞，取消尚未执行的工作可跳过。

已经进入原生调用的工作不能强杀。工作线程持有数据目录作用域租约，涵盖取消后的按键释放、光标归还和原生对象销毁；同目录下一引擎、包括切换角色，必须等旧清理结束才开始。租约注册使用弱引用回收，不在核心Drop里等待系统线程。

平台确认期限2秒，全进程平台输入工作线程最多64个。超时后结束会话/引擎、停止继续接受输入，底层线程保留租约直至真正退出；不能让独立心跳掩盖已经失去响应的原生输入工作。清理尽力释放所有已尝试按下的键和按钮，保持鼠标返回位置；失败Up在工作线程中保留、正常会话结束先reset，reset失败则停止整个引擎并在Drop再次尝试，不能带入下一会话。无法保证永久挂起的系统调用立即归还控制。

## 输入会话收发

Framed可拆成独立Reader/Writer，保留握手预读的完整帧与半帧；读取取消不丢数据。可靠流只有一个writer，不并行写协议帧。

会话独立reader接收数据并回应Ping，writer最多128条排队和500ms总发送期限（包含该队列等待）。平台调用等待期间，reader仍能处理心跳。普通输入进入最多256条的接收队列并保留解码时刻；核心输入状态机仍逐条执行。过载或发送失败终止会话并走按键释放路径，不丢弃可靠KeyUp后继续共享。

应用outbox遇到writer背压时暂停消费，保留原普通移动合并与顺序屏障；心跳不越过可靠控制帧改变输入顺序。QUIC的Fence、控制消息、ACK仍有序，数据报仅在当前屏障获ACK后发送，最终位置补偿仍可靠。发送完成仅表示交给底层，不是对端已经处理或呈现。

心跳的计时在入writer队列前开始，在reader处理匹配Pong时结束。保留最多32个已发nonce，匹配后消费一次，重复或伪造回复不刷新存活状态、不污染RTT。此数值仍为应用协议往返，但独立于本机输入队列执行；不能用低RTT说明键鼠注入或屏幕显示没有排队。

## 拖放与回执

Overlay提供独立Send的DragReader，窗口仍在原有UI线程。拖放剪贴板与metadata查询交给单个有界串行工作线程，近边缘最多20Hz，一项在飞；结果绑定拖动代次，结束/新拖动/引擎重置的迟到结果丢弃。实际Dropped路径不等待预览或摘要。慢初始基线下预览可能延后，避免把旧拖放剪贴板误认成新拖动。

回执清理先在短状态锁内保留(peer,id)，再锁外检查身份及删除；等待中的新通告受正常任务预算约束，清理完成前不发送接受、不打开恢复。真正阻塞线程持有保留标记，调用方取消不会提前释放；错误/panic由RAII释放。重新检查目录、回执身份与完成时间，避免旧扫描删除已刷新回执。

## 诊断口径

- inject从reader解码时刻计到有序平台调用返回，包含接收队列、平台线程等待，不含系统呈现。
- send及heartbeat_send包含有序writer排队到write/flush返回，仍不等网络ACK。
- scheduler是该任务的定时检查迟到，可能包含等待平台确认，并不自动等于整个CPU运行时阻塞。
- 每次尖峰继续保留本来源前2/触发1/后2窗口；增加触发前后15秒关联来源，最多16窗、历史最多8窗给后续留空间。连接尖峰优先关联本机公共引擎，公共引擎尖峰关联连接，避免无关peer挤走本机指标。只有“时间接近”，不得相加减为同一事件分段。
- 每来源生命周期保留已收到窗口的count、max、>100ms累计，最多128来源；不随4个详细上下文淘汰而丢掉较早最高值。事件合并可能漏窗口，不能宣称无损全程追踪。来源重连或引擎换代清除对应记录。

配置和设备线协议不变，不主动改变TCP/QUIC偏好。诊断历史只在完整导出文件呈现，不放大每次IPC状态，也不记录键值、文字和光标轨迹。

## 验证要求

覆盖慢光标操作期间心跳继续、Enter/Leave确认顺序、取消中的KeyDown释放、旧代清理不影响重启；慢拖放查询期间实际Dropped继续、过期结果丢弃；慢回执清理期间无状态锁阻塞、登记/删除竞态和取消/panic；可靠流读写分离、半帧保留、输入接收排队计时及nonce匹配；默认/全feature回归、Windows交叉检查和两平台原生CI打包。

本地最终结果：默认Rust477通过、全feature488通过，各3项既有环境依赖忽略；Flutter141通过。默认/全feature/Windows全target Clippy、结构lint、格式及cargo-deny通过。详见repair-validation.md。自动回归没有原生双机键鼠交互，不据此声称网络尖峰已消除。
